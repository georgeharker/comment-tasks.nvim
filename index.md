# comment-tasks.nvim

A Neovim plugin that bridges 10+ task management systems with code comments:
create, update, and complete tasks (ClickUp, GitHub Issues, Jira, Linear,
Asana, and more) directly from `TODO`-style comments, keeping the task URL
embedded in your code for traceability.
